% Fixed-threshold (-35dB) parameter sweep: which of ratio/knee/attack/
% release performs best when threshold is held at a single
% conservative-balance point. Companion to recommended_settings_table.tex
% (which optimizes threshold itself) - this answers a different question:
% given threshold is already fixed, where do the other four parameters
% perform best. See analysis/lhs_sweep_fixed_thr35_findings.txt for full
% methodology (100-point Latin Hypercube, Advanced mode only, ratio/knee/
% attack/release sampled with threshold pinned at -35dB).
%
% Requires packages already in main.tex's preamble: booktabs, siunitx.
% Also requires colortbl for \cellcolor - see parameter_sweep_table.tex's
% header comment (add \usepackage{colortbl} or change to
% \usepackage[table]{xcolor}).
%
% COLOR CODING matches the other tables: grey headers on the swept-input
% columns (Ratio, Knee, Atk., Rel., and the row-label column), green/
% yellow/orange cells on Margin Gain/STOI Gain/Loud. Red. respectively.
% With only one real data row here (a single best point, not a ranked
% list), there's no per-table min/max to scale a heatmap against like the
% other tables do - all three metric cells use a fixed, consistent
% intensity, matching how a strong result would read on those other
% tables' scales, rather than implying a false relative ranking between
% the three cells. The "Standardized coeff." row is a different kind of
% information (regression output, not a settings/outcome row) and is left
% uncolored.
