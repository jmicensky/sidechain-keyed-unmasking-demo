stem files. Effect on the numbers was small, as expected: unprocessed
mean margin moved from -3.32dB to -3.19dB; basic/advanced values are
unchanged (already computed from the real stems); STOI moved by
<0.001 in every run; rankings are unaffected.

======================================================================
PSYCHOACOUSTIC PARTIAL-LOUDNESS / MASKED-THRESHOLD ESTIMATE
======================================================================
Method: ISO 532-1 (Zwicker) loudness via MOSQITO, stationary per-segment
(nperseg=8192, noverlap=4096 @ 48kHz, ~85ms hop) - not the full
time-varying model (computational-cost tradeoff).
Calibration: full-scale digital peak assumed = 100 dB SPL. Absolute %
values are calibration-dependent; the relative comparison across
conditions (same calibration throughout) is far more robust.
"Masked" = Dialogue specific loudness in a critical band/frame <=
the reconstructed masker specific loudness in that band/frame (masker
excitation used as an approximate masking-threshold proxy - NOT the
full Moore & Glasberg partial-loudness/masking-index model).
Masker reconstructed by exact time-domain subtraction (mix - dry
Dialogue), valid because Dialogue always takes the dry/unducked path
regardless of duck mode. Averaged over frames where Dialogue's own
loudness exceeds 10% of its peak (770/955 frames, 80.6%, for this clip).
Row order matches the mean-margin-gain ranking above, for direct
cross-reference. "Unprocessed" here is also the true stem sum (see
note in the section above), not the reference blend.
