NOTE ON THE MEASUREMENT BAND: masking margin is measured on 721-3883Hz,
not Dialogue's full nominal 400-7000Hz range. Reason: this script's own
analysis bandpass filter, applied to the rendered output audio,
interacts with Advanced mode's own internal crossover filter (a
different filter shape) near the shared nominal edges. This inflated
Basic mode's measured margin gain relative to Advanced's by a spurious
~0.9-1.0dB at the unpadded edges, even though the engine applies
bit-identical gain within the class's core band in both modes (verified
directly via the engine's own reported gain). Padding by 0.85 octaves
per side closes this gap to within 0.13dB on every one of these 9 runs
(see the "measurement gap" line per run above). This is a real
reduction in measured bandwidth (Dialogue's 4.1 nominal octaves becomes
~2.4 measured octaves), accepted as a deliberate tradeoff rather than a
smaller pad that would leave the gap only partially closed. STOI is
unaffected (it operates on the full-band signal directly, no bandpass
filtering involved).

======================================================================
PSYCHOACOUSTIC PARTIAL-LOUDNESS / MASKED-THRESHOLD ESTIMATE
======================================================================
Method: ISO 532-1 (Zwicker) loudness via MOSQITO, stationary per-segment
(nperseg=8192, noverlap=4096 @ 48kHz, ~85ms hop) - not the full
time-varying model (computational-cost tradeoff).
Calibration: full-scale digital peak assumed = 100 dB SPL. Absolute %
values are calibration-dependent; the relative comparison across
conditions (same calibration throughout) is far more robust.
"Masked" = Dialogue specific loudness in a critical band/frame <=
the reconstructed masker specific loudness in that band/frame (masker
excitation used as an approximate masking-threshold proxy - NOT the
full Moore & Glasberg partial-loudness/masking-index model).
Masker reconstructed by exact time-domain subtraction (mix - dry
Dialogue), valid because Dialogue always takes the dry/unducked path
regardless of duck mode. Averaged over frames where Dialogue's own
loudness exceeds 10% of its peak (770/955 frames, 80.6%, for this clip).
Row order matches the mean-margin-gain ranking above, for direct
cross-reference. "Unprocessed" here is also the true stem sum, not the
reference blend.

NOT affected by the margin-measurement padding fix above (this metric
uses MOSQITO's own Bark-band filterbank, not this project's bandpass
filter, so the same crossover-edge artifact does not directly apply).
HOWEVER: Basic and Advanced show a comparable-looking gap here too
(e.g. Run 1: Basic 36.3% masked vs Advanced 42.3% masked, a 6pp
difference) that has NOT been investigated for the same root cause -
flagging this as an open question rather than assuming it is fine.
